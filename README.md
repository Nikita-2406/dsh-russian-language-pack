# Русский языковой пакет для DeepSeek Harness

Русификация веб-интерфейса DeepSeek Harness: 61 словарь, ~2800 строк.

## Установка

1. Откройте **Плагины → Добавить плагин → Установить сторонний плагин**
2. Вставьте адрес:

   ```
   https://github.com/Nikita-2406/dsh-russian-language-pack.git
   ```

3. Установите и перезапустите приложение, если попросят.

Или командой:

```
dsh plugin add https://github.com/Nikita-2406/dsh-russian-language-pack.git
```

## Язык

Русский включится сам после установки. Переключить: **Настройки → Основные → Язык → Русский / English**.
